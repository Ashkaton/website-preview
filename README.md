# Cargasm — страница запуска

Страница «Момент настал»: по нажатию кнопки **cargasm.club** запускается музыка, идёт отсчёт, затем ролик о возможностях Cargasm (карточки и сборка логотипа). В конце происходит переход на сайт.

Ролик не видеофайл. Он рисуется в браузере (HTML/CSS/JS) по часам музыки: звук и картинка не расходятся, всё резкое на любом экране, а вся страница весит около 13 МБ.

Опубликовано через GitHub Pages из ветки `main`: https://ashkaton.github.io/website-preview/

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Страница запуска: стартовый экран, звёзды, отсчёт, музыка, показ сцены, переход на сайт. Весь код внутри |
| `music-liquid-art-cut.mp3` | Трек «Liquid Art» (Coma-Media), обрезанный под ролик, 150 BPM |
| `logo.png` | Логотип на стартовом экране |
| `scene/scene.html` | Сцена ролика: фон, 3D-карусель карточек, подписи, рисование логотипа. Открывается в `<iframe>` |
| `scene/cards/*.png` | 8 карточек разделов (980×1580, ×2 от размера на экране) |
| `scene/Logo.png` | Логотип над каруселью |
| `scene/bg-loop.mp4` | Фоновое видео сцены (зацикленное, 1280×720, без звука) |

## Как это работает

1. **Стартовый экран.** Звёзды рисуются на `<canvas id="starfield">`. Кнопка `#launch` (или Enter) вызывает `begin()`.
2. **Нажатие.** Нажатие разблокирует звук в браузере. Трек заранее декодирован и склеен в `AudioBuffer` (с нарастанием и затуханием громкости) и стартует через `MUSIC_DELAY` = 2.8 с. За это время плавно уходят надписи, логотип и подвал.
3. **Таймлайн.** Всё дальше считается от старта музыки по аудио-часам (`launchTime()`), в функции `timeline()`:
   - отсчёт 5…0 на удары малого барабана (`COUNTDOWN`);
   - звёзды разгоняются и вытягиваются в линии;
   - на дропе (`DROP`) появляется сцена.
4. **Сцена.** `scene/scene.html` не играет сама: страница каждый кадр вызывает в ней `render(t, bass)`.
   - `t` — время сцены;
   - `bass` — громкость баса трека (0…1). Её считают заранее из самой музыки, от неё карусель «качается».
   - Шаг карусели и длительности передаются в сцену через URL (`SCENE` → `?step=…&views=…&hold=…&beat=…`), так что ритм задаёт страница запуска под конкретный трек.
5. **Конец.** Когда сцена дошла до конца (`VIDEO_LEN`), выполняется `location.assign(CONFIG.destination)`.

Если окно шире или уже 16:9, кадр сцены вписывается целиком, а фон растягивается на всё окно (`fit()` в `scene.html`). На вертикальных экранах (телефоны) включается вертикальная раскладка 1080×1920.

## Настройки (`index.html`, объект `CONFIG`)

```js
const CONFIG = {
  launchEndpoint: "",                 // если задан — POST сюда перед запуском (например, активировать портал); при ошибке запуск не начнётся
  scene: "scene/scene.html",
  music: "music-liquid-art-cut.mp3",
  destination: "https://cargasm.club/" // куда перейти после ролика
};
```

Секреты и токены в этот файл не класть: он публичный.

## Тайминги (`index.html`, блок «Таймлайн»)

Все времена в секундах от старта музыки и привязаны к ударам трека (150 BPM, такт `BAR` = 1.59586 с, доля = `BAR / 4`).

| Константа | Значение | Что |
|---|---|---|
| `MUSIC_DELAY` | 2.8 | пауза между нажатием и стартом музыки |
| `COUNTDOWN` | 4.04 … 12.04 | секунды появления цифр 5…0 (удары малого во вступлении) |
| `DROP` | 12.86 | дроп: появляется сцена |
| `SCENE.step` | 2 такта | смена карточки (8 карточек = вся громкая часть, 16 тактов) |
| `SCENE.hold` | … | от затихания музыки до конца: 3 доли до вспышки G, 10 долей сборки логотипа, ещё 1.2 с |
| `FADE_IN` / `FADE_AT` | 4 с / последние 2 с | нарастание и затухание музыки |

**Если меняется трек**, найдите в нём удары: дроп, удары малого во вступлении и момент затихания. Затем пересчитайте `DROP`, `BAR`, `COUNTDOWN` и `SCENE` (G приходится на `DROP + 16 тактов`). Сцену менять не нужно.

## Сцена (`scene/scene.html`)

- `CARDS`: файлы карточек и подписи под ними (польский).
- Карусель: `carouselPos()`, позиции `X/Z/RY/RZ/BLUR`.
  - Карточка приходит на долю резко, с лёгким толчком.
  - Перед логотипом карточки собираются в одну и уходят.
- Логотип: наброски и вспышка G, затем буквы, плашка CLUB и свечение. События после вспышки привязаны к долям (`LOGO_BEATS`).
- Свечение плашки CLUB висит на обёртке `#plateWrap`, а не на самом `<svg>`: Safari обрезает фильтры на `<svg>` по его границам.
- Сцену можно открыть отдельно для проверки, она проиграется сама по кругу: `scene/scene.html?horizontal&step=3.19&beat=0.4` (или `?vertical`).

## Запуск локально

Нужен любой статический сервер. Из `file://` не заработает, потому что музыка грузится через `fetch`:

```bash
npx serve .
```

Затем откройте адрес, который покажет сервер. Звук включается только после нажатия на кнопку: это требование браузеров.

## Браузеры и проверка

- Проверено в Chrome/Chromium на 1920×1080, 1470×956 (MacBook Air 13″), 2560×1080 и 390×844 (телефон). Заказчик проверил на своём MacBook.
- iPhone: в беззвучном режиме (переключатель сбоку) музыка может не играть.
- Если видео-фон сцены не запустился (например, режим энергосбережения в Safari), он двигается перемоткой, а не замирает.
